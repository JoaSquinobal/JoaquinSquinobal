# Analisis set de datos 
## Steam Dataset

Podría usar el dataset de steam para entrenar un modelo que intente predecir si un juego va a ser popular o no según la cantidad de recomendaciones o jugadores que tenga. Para esto usaría un Machine Learning supervisado, porque el dataset ya tiene información de muchos juegos y sus resultados, entonces el modelo puede aprender a partir de esos casos.

Los features que me parecen más útiles serían cosas como el precio del juego, el género, la fecha de lanzamiento, las reseñas positivas y negativas, etc. Me parecen importantes porque esas cosas pueden influir bastante en si un juego termina siendo popular. Por ejemplo, si un juego tiene muchas reseñas positivas o si la gente pasa muchas horas jugándolo, probablemente sea un juego que gusta mucho. Con esos datos el modelo podría encontrar patrones y después tratar de predecir qué juegos nuevos podrían llegar a tener éxito.

**Extra:**
Otra cosa interesante que se podría hacer con el steam dataset es crear un sistema de recomendación de juegos. La idea sería usar la información del dataset para recomendarle a un usuario juegos que probablemente le gusten, basándose en las características de otros juegos.

Por ejemplo, el modelo podría analizar features como el género del juego, el precio, las reseñas positivas y negativas, el tiempo promedio de juego y las etiquetas. Con esos datos podría encontrar juegos que sean parecidos entre sí. Entonces, si a un jugador le gusta un juego con ciertas características, el sistema podría recomendarle otros juegos que tengan características similares.
